# bwax.services

Informational static site demonstrating Brazilian wax epilation technology & reliability insights.

**Domain available for acquisition** → [sales@desertrich.com](mailto:sales@desertrich.com)

## Stack

- **Astro 5** — pure static output (`output: 'static'`)
- **Tailwind CSS 3** + Typography plugin
- **TypeScript** (strict)
- **@astrojs/sitemap**
- **Cloudflare Workers Static Assets** (no adapter required)

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
# Output lives in ./dist

# Deploy to Cloudflare Workers Static Assets
npx wrangler deploy
```

Or connect the GitHub repo to Cloudflare Pages / Workers and set build command `npm run build`, output directory `dist`.

## Key Features

- Fully static, edge-optimized
- Complete Open Graph + Twitter meta
- JSON-LD structured data (WebSite, WebPage, FAQPage)
- Mobile-first responsive design
- Sophisticated domain-acquisition CTA in footer
- robots.txt + auto-generated sitemap
